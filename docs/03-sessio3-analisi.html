3.1 Anàlisi Exploratòria de les Dades

Fins ara hem vist un sol tipus de gràfic, concretament un gràfic de dispersió. Aquest s’utilitza quan volem visualitzar l’associació entre dues variables numèriques contínues, com per exemple, el temps d’intubació i l’edat dels pacients. Però quin seria el millor gràfic per representar el temps d’intubació en funció del sexe?

Per saber quin és el millor gràfic per representar les variables que ens interessen, hem de conèixer de quin tipus són:

  • Variabla categòrica: els seus valors són categories.

    • Categòrica nominal: les categories de la variable no segueixen un ordre predefinit.
      Mètode de laringoscòpia: Standard Macintosh #4/AWS Pentaz Video
      Sexe: Home/Dona
    • Categòrica ordinal: les categories de la variable segueixen un order concret i lògic
      Mal de coll després de la intervenció: 0 = none; 1 = mild; 2 = moderate; 3 = severe

  • Variabla numèrica: els seus valors són numèrics

    • Numèrica discreta: els seus valors no són infinits, sinó que són nombres enters
      Nombre d’intents: 1, 2, 3
    • Numèrica contínua: els seus valors poden ser infinits
      BMI: rang numèric entre 31-61


El paquet ggpubr permet graficar una gran varietat de gràfics en funció de cada situació
